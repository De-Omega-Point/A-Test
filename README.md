# A-Test 🇦🇺

A visual, interactive Australian citizenship learning system built for active recall and mastery.

## V2 Learning Lab
- Structured learning content across the four official testable areas
- Interactive concept infographics and timelines
- Flashcards with known / review-again tracking
- Reinforcement drills by topic or mixed mode
- Local mastery and score persistence
- Australian-values hard-gate emphasis
- Responsive, dependency-free static web app
- GitHub Pages deployment workflow

## Learning loop
Learn → Visualise → Recall → Reinforce → Retest

Open `index.html` locally or use the GitHub Pages deployment.

> Independent study aid. Confirm current requirements and official study material with the Australian Department of Home Affairs.
